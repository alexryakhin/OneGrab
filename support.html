Frequently asked questions

How do I download a file?

Copy a direct file URL (a link that points to the file itself — for example ending in .pdf, .zip, or .mp4), open OneGrab, and tap Save or Save from Clipboard. When it finishes, open, share, or export from your Saved list.

What kinds of links work?

OneGrab downloads open file links only — URLs that point to a file, not a webpage. Webpage or watch/share page links are refused. If a link isn’t a direct file, the app will tell you.

How do I restore my subscription?

Open OneGrab, tap the settings (gear) icon, then Restore purchase. Your subscription will be restored if it’s still active.

Downloading isn’t working. What should I try?

Make sure the URL is a direct file link (not an HTML page). Check your internet connection and try again. If it still fails, email us with the link and we’ll look into it.
