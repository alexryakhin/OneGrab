Domande frequenti

Come scarico un file?

Copia un URL di file diretto (un link al file — es. che termina con .pdf, .zip o .mp4), apri OneGrab e tocca Salva o Salva dagli Appunti. Poi apri, condividi o esporta dall’elenco Salvati.

Quali link funzionano?

OneGrab scarica solo link di file aperti — URL a un file, non a una pagina web. Le pagine web vengono rifiutate. Se il link non è un file diretto, l’app te lo comunica.

Come ripristino l’abbonamento?

Apri OneGrab, tocca l’ingranaggio e poi Ripristina acquisto. L’abbonamento viene ripristinato se è ancora attivo.

Il download non funziona. Cosa fare?

Assicurati che l’URL sia un link di file diretto (non HTML). Controlla la connessione e riprova. Se fallisce ancora, inviaci il link via e-mail.
